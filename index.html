구글 시트에서 받은 연결 파일을 불러오거나 연결 정보를 붙여 넣으세요. 이 기기의 기존 완료 기록도 함께 옮깁니다.

연결 정보는 개인 기록에 접근하는 열쇠입니다. GitHub나 공개 게시물에 올리지 마세요. 다른 기기에서는 같은 연결 파일을 한 번 불러오면 됩니다.

처음 한 번 연결 준비
  1. 개인 구글 드라이브에 기록 시트를 만듭니다. 기록 시트 양식을 Google 스프레드시트로 가져올 수 있습니다.
  2. 시트의 확장 프로그램 → Apps Script에서 기록 연결 코드를 붙여 넣고 저장합니다.
  3. 배포 → 새 배포 → 웹 앱에서 실행 사용자는 나, 액세스 사용자는 모든 사용자로 선택합니다. 구글의 계정 권한 확인은 직접 진행합니다. 시트 자체는 비공개로 유지할 수 있습니다.
  4. 시트를 새로 열고 게임 기록 연결 → 처음 연결 / 연결 정보 보기를 눌러 연결 파일을 받습니다.
  5. 위에서 연결 파일을 불러옵니다. 구글 설정에서 웹 앱 배포를 제한한 계정은 다른 저장 방법이 필요할 수 있습니다.

이 앱은 기록 저장에 필요한 별도의 개인 연결 키를 확인합니다. 게임 기록과 플레이어 점수 시트는 조회용이며, 기록 삭제는 웹앱에서 하면 다른 기기에도 반영됩니다.

연결 후에는 구글 시트가 공통 기록장입니다. 인터넷이 끊겼을 때의 전송 대기분과 최근 기록 사본은 기기에 임시 보관하며, 저장 확인 후 동기화 완료로 표시합니다. 진행 중인 게임의 이어하기 파일은 기기별로 유지합니다.
